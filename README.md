# 🛒 Daisyfu Market - POS & Marketplace System

Aplikasi kasir (POS) dan katalog marketplace modern berbasis web yang terintegrasi dengan Firebase dan dideploy di Vercel.

🔗 **Live Demo:** [https://mp-9lln.vercel.app/](https://mp-9lln.vercel.app/)

---

## ✨ Fitur Utama
- 🛍️ **Katalog Produk**: Menampilkan daftar produk dengan filter kategori, pencarian, dan label best seller.
- 🛒 **Keranjang Belanja (Cart)**: Tambah, kurangi, dan hitung total belanja secara realtime.
- 🧾 **Laporan & Transaksi**: Riwayat transaksi kasir dan cetak struk belanja.
- 📱 **Barcode Scanner**: Dukungan scanning barcode (EAN-13 / Code128).
- 🔐 **Autentikasi & Database**: Terhubung dengan Firebase Firestore & Auth, serta dilengkapi **Mode Demo** offline.

---

## 🛠️ Teknologi yang Digunakan
- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript
- **Backend / Database**: Google Firebase (Firestore, Auth, Storage)
- **Deployment**: Vercel
- **Barcode**: JsBarcode Library
